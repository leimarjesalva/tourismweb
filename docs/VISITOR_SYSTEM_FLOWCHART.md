├── GET  api.php?action=list_shops
│    └── Returns: shops array

├── GET  api.php?action=list_categories
│    └── Returns: product categories

ITINERARIES:
├── POST api.php?action=add_itinerary
│    └── Input: { title, days, destinations, email, name, anonymous }

EVENT LOGGING:
├── POST api.php?action=log_event

│    └── Returns: { success: true }
